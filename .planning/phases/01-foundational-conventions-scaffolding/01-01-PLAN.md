## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Xcode build → artifact | The .xcodeproj defines what ships in the .ipa. Misconfiguration here cascades to every later phase (deployment target, test target isolation). |
| Simulator-CI ↔ Device-CI | D-03 mandates separate test targets so simulator builds never execute Secure Enclave code paths (Pitfall P8). This plan creates the target boundary. |

| T-01-03 | Information Disclosure | SwiftUI ContentView.swift residual in build | mitigate | Explicit `git rm` in Task 2 + Acceptance Criterion 5 greps for `import SwiftUI` in validationLedger/ — fails if any remains. |
