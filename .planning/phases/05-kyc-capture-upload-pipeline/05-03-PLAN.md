<objective>
The capture-tier services for Phase 5: fresh-GPS acquisition (`GeoContext`), capture-time EXIF GPS injection (`GPSMetadataInjector`), and the camera/face-detection services behind protocols (`CameraSession`, `FaceQualityGate`).

Purpose: KYC-04's trust boundary is "GPS metadata attached at capture time before any `UIImage` conversion that would strip EXIF" (RESEARCH Pitfall 6 — the product's entire fraud-detection premise depends on the GPS tag). KYC-02 needs a Vision quality gate (detected/centered/in-focus) — liveness is deferred. These services are built before the capture UI (plan 05) and `KYCUploader` (plan 04) because both consume them. The pure logic (`GeoContext` freshness gate, `GPSMetadataInjector` round-trip, `FaceQualityGate` decision) is simulator-testable; the live `AVCaptureSession` body is device-only (RESEARCH Pitfall 1) and stays behind a protocol.

Output: `GeoContext` actor, `GPSMetadataInjector` utility, `CameraSession` + `FaceQualityGate` protocol-backed services.

TDD plan: RED scaffolds from plan 01 (`GeoContextTests`, `GPSMetadataInjectorTests`, `FaceQualityGateTests`) drive RED→GREEN→REFACTOR for the testable logic.
</objective>

  <behavior>
    - `refresh()` calls the injected `LocationProvider` and caches the returned `CLLocation`.
    - `freshLocation()` returns the cached fix when it is <30s old and accuracy is ≤100m.
    - `freshLocation()` rejects (throws) when the cached fix is >30s old — even if it was fresh when cached.
    - `freshLocation()` rejects when the cached fix has horizontalAccuracy >100m or <0.
    - With no fix ever cached, `freshLocation()` rejects rather than returning a stale/nil value.
  </behavior>
  <action>
    Create `GeoContext` as a `public actor` in `Core/Identity/Geo/` (the directory allow-listed for coordinate literals). It is a thin cache OVER the existing `LocationProvider` (CONTEXT D-discretion — build on it, do not re-bridge CoreLocation).

    - `init(locationProvider: any LocationProvider, maxAge: TimeInterval = 30, maxAccuracy: CLLocationDistance = 100, now: @escaping @Sendable () -> Date = Date.init)`. The injected `now` makes the freshness gate deterministically testable.
    - `func refresh() async throws` — call `locationProvider.currentLocation(maxAge:maxAccuracy:)` and store the returned `CLLocation` as the cached fix. KYC-flow start calls this once.
    - `func freshLocation() async throws -> CLLocation` — read the cached fix; re-validate `now() - fix.timestamp <= maxAge` and `0 <= fix.horizontalAccuracy <= maxAccuracy`; if stale/inaccurate, call `refresh()` once and re-validate; if still failing, throw `LocationError.staleFix` / `.lowAccuracy`. If no fix has ever been cached, attempt one `refresh()` then throw if it still fails.
    - Reuse `LocationError` — do not define a parallel error type.
  </action>
