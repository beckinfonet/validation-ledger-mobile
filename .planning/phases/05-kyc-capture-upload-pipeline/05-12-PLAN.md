<objective>
Create the four device XCUITest files that automate the 4 physical-device UAT items from
`05-VERIFICATION.md`. Each test launches the app with a `-KYCTestSeedForUITest` mode from plan
05-11, drives live UI, and asserts the device-only behavior that an in-process XCTest cannot.

Purpose: `validationLedgerDeviceTests` (in-process XCTest) cannot kill/relaunch/background the
app or tap live UI. `validationLedgerUITests` (XCUITest, a separate driver process) can:
`XCUIApplication().terminate()` is a real ungraceful kill, `.launch()` relaunches,
`XCUIDevice.shared.press(.home)` backgrounds, and element queries tap live UIKit. These four
files convert SC-2, D-08, D-12, and the Test-10 background/foreground portion into automated
runs on the self-hosted device CI lane.

Output: Four XCUITest files in `validationLedgerUITests/`, written on XCTest (STACK-03 — Swift
Testing does not support `XCUIApplication`), mirroring the conventions of the existing
`RoleShellSmokeTests.swift` and `LimitedTrustBannerTests.swift`.
</objective>
