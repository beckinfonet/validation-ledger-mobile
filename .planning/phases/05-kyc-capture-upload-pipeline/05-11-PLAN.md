<objective>
Add three `#if DEBUG`-gated launch-argument test seams to the app composition root so that
the device XCUITests in plan 05-12 can seed the exact KYC states they must verify. XCUITests
run in a separate driver process and cannot reach internal app state; the only crossing point
is launch arguments parsed at scene-connect time.

Purpose: The 4 device-UAT items (SC-2, D-08, D-12, Test-10 background/foreground) each need a
specific starting state — a non-verified account, a verified/under-review account that reaches
the role shell, and a mid-upload KYC session on disk. Without these seams the XCUITests have no
way to arrive at those states deterministically on a CI device runner.

Output: One new launch argument `-KYCTestSeedForUITest <mode>` (three modes), parsed in
`SceneDelegate`, bridged into `AppContainer` via a DEBUG static seam, plus a DEBUG-only
mid-upload seeding helper on `KYCSessionStore`. All strictly `#if DEBUG` — zero bytes in Release.
</objective>
