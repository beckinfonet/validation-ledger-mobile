<objective>
Build the Phase 8 Loads feature surface under the NEW `validationLedger/Features/Loads/` directory:

1. `LoadListViewModel` — a `@MainActor public final class` mirroring `KYCStatusViewModel` (state-machine + `didSet → onStateChange` + initializer-DI). 4-case `State`: `.loading`, `.empty`, `.loaded(items: [LoadListItem], nextCursor: String?)`, `.error(message: String)`. Stores `nextCursor` per D-05 but never reads it. Idempotent `refresh()` semantics per UI-SPEC.
2. `LoadListViewController` — programmatic UIKit. `UICollectionViewCompositionalLayout(.list)` + `UICollectionViewDiffableDataSource<LoadListSection, LoadRowItem>` with `enum LoadListSection { case main }` (D-08). `UIRefreshControl` attached directly. Single `render(_ state:)` dispatcher: `.loading` swaps to a SKELETON OVERLAY (separate background view — NOT a datasource swap, RESEARCH §Anti-Patterns), `.empty` uses `UIContentUnavailableConfiguration`, `.error` uses either `UIContentUnavailableConfiguration` (if the A1 spike confirms `accessibilityIdentifier = "loads-list.error-state.retry"` is reachable) OR a hand-rolled stack-view (RESEARCH §Open Question 1). iPad SC-#5 via compositional-layout `section.contentInsetsReference = .readableContent`.
3. `LoadRowCell` — `UICollectionViewListCell` composing `VerificationBadgeView` + `LoadStatusBadgeView` + DS-token-styled labels for the 7-field freight row (reference, origin→destination, pickup, deliver, equipment, weight, rate). 44 pt min touch target intrinsic. Accessibility identifiers per UI-SPEC § Copywriting (on the CELL, not subviews — Pitfall 6). `prepareForReuse` resets verification badge to UNVERIFIED (T-08-07).
4. `SkeletonLoadRowCell` — silhouette-match shimmer (`CAGradientLayer` + `CABasicAnimation`, ~1.0–1.5 s loop, infinite repeat). Re-add shimmer in `prepareForReuse` and `layoutSubviews` (Pitfall 1). Top-of-file comment documents app-wide skeleton-with-shimmer pattern (D-10).
