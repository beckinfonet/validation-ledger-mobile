<objective>
The `KYCUploader` actor — the resumable, retrying, idempotency-keyed chunked-upload pipeline. UPL-01 (chunked upload, 512 KB default), UPL-02 (disk-persisted resume), UPL-03 (jittered backoff, 5-attempt cap), UPL-04 (progress per chunk ack). Also closes SC-5 (no duplicate chunk commits under transient failure).

Purpose: this is the reliability core of Phase 5 — getting six identity artifacts to the backend over poor dock LTE without restarting from zero and without DDoSing the backend. It composes shipped primitives: the `APIClient` facade, the four KYC endpoints, the `IdempotencyInterceptor` header seam (plan 01), the `KYCSessionStore` (plan 02). Per the RATIFIED USER DECISION it keeps the shipped JSON `chunkData`-in-body contract and runs the chunk loop on the normal foreground session — it does NOT switch to file-based background uploads (that is an explicit M2 follow-up).
