Output: 1 new production file (`StatusTimelineView.swift`) + `LoadDetailBodyView.swift` modification to host the timeline inside `timelineContainer` + the Plan-02 timeline snapshot test populated with 7 test methods (one per primary lifecycle state + cancelled terminal).
