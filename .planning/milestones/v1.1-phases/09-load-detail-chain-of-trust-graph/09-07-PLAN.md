let sheetVC = VerificationBasisSheetViewController(node: node, integrity: chainOfTrust.integrity)

if let sheet = sheetVC.sheetPresentationController {

KYC row:
- `kycCompletedAt != nil` → "KYC verified {relative time}" + checkmark.seal.fill (DS.Colors.primary)

- `.bound` → "Device bound · {shortDeviceLabel} · since {month year}" + lock.shield.fill (DS.Colors.primary)

- `.revoked` → "Device binding revoked" + lock.slash (DS.Colors.destructive)

USDOT row (switch on USDOTAuthorityStatus; planner confirms enum cases by reading USDOTAuthorityStatus.swift):
- `.active` → "USDOT {number} · Authority active" + checkmark.shield.fill (DS.Colors.primary)
- `.suspended` → "USDOT {number} · Authority suspended" + exclamationmark.shield (DS.Colors.caution)
- `.revoked` → "USDOT {number} · Authority revoked" + xmark.shield.fill (DS.Colors.destructive)
- `.notApplicable` → row not rendered (UI-SPEC line 714)
- Row is ENTIRELY ABSENT for Shipper / Factoring (UI-SPEC line 419 D-09) — controlled by `node.role` switch, NOT by usdotAuthorityStatus

Prior relationships row content:
- Section header: "Prior relationships ({count})" or "Prior relationships" + empty-state line "First time working together." when `node.priorRelationships.isEmpty`
- Each row: load ref ({.headline}) + framing ({.footnote}) + relative timestamp ({.footnote}) + chevron.right (DS.Colors.labelSecondary)
- accessibilityTraits = .staticText (NOT .button per D-10 — the affordance is rendered but the tap is inert in v1.1)

- Renders ONLY when `partyID ∈ chainIntegrity.implicatedNodeIDs`
- Rounded card; soft tint (caution → 0.15 yellow / compromised → 0.15 red)
- Title: "Why this party is flagged" (NSLocalizedString)
