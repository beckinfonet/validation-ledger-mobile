## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server JSON → iOS Decodable | Untrusted server input crosses here; the Decodable init is the validation layer |
| iOS code → leaf enum value | Trust-level decisions on the iOS UI read these enum values; a wrong default upgrades trust |
| LoadAction string → URL path | LoadAction.pathSegment is interpolated into URL paths sent server-side; the path determines which mutation the server performs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing | VerificationState decoder | mitigate | D-09 fail-closed init(from:) maps unknown wire values to `.unverified`; missing parent field throws DecodingError. Covered by Task 2 tests (known/unknown/missing). |
| T-07-02 | Tampering | ChainIntegrity.Verdict decoder | mitigate | D-09 parity — unknown wire values default to `.compromised` (most-suspicious). Covered by Task 3 tests. |
| T-07-03 | Tampering | LoadStatus decoder | accept | Unknown LoadStatus throws DecodingError (Swift's synthesized init). A server superstring on status is a contract bug, not a fraud vector — the entire Load fails to decode loudly, surfacing the bug. Distinct from D-09's verification-only fail-closed rule. |
| T-07-04 | Elevation of Privilege | LoadAction enum (closed) | mitigate | LoadAction is NOT Decodable — actions are never read from server payloads. Cannot be forged via a JSON response. Sent client→server via URL path segment only. |
| T-07-05 | Information Disclosure | DeviceBindingStatus / USDOTAuthorityStatus | accept | Indicative case sets; closed enums; no PII; render-only client behavior. |
| T-07-SC | Tampering | npm/pip/cargo installs | n/a | Phase 7 installs zero external packages. No package-legitimacy gate required. |
