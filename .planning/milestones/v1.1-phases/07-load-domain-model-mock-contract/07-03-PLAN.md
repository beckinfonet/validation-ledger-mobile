<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LoadAction → URL path segment | Action authority is encoded in the URL; a wrong pathSegment routes a "cancel" to a "tender" endpoint server-side |
| LoadActionEndpoint.body → wire JSON | RequestBody fields cross to the server; the typed RequestBody is the validation boundary |
| Server JSON → LoadListEndpoint.Response / LoadDetailEndpoint.Response / LoadActionEndpoint.Response | Untrusted input crosses here; each Response's Decodable conformance is the validation layer (delegated to the Plan 01/02 fail-closed value types) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-12 | Tampering | LoadActionEndpoint.path computed from action.pathSegment | mitigate | LoadAction is a closed enum (Plan 01); pathSegment is a deterministic function defined in Plan 01. Test 3 verifies all 6 action→pathSegment mappings. No untyped string interpolation. |
| T-07-13 | Repudiation | POST without Idempotency-Key | mitigate | D-19 — `method = .post` auto-picks up the v1.0 IdempotencyInterceptor wired in AppContainer.swift:476. Phase 4 IdempotencyInterceptorTests covers the wiring; Phase 7 inherits. |
| T-07-14 | Information Disclosure | LoadDetailEndpoint Response payload size | accept | Embedded ChainOfTrust (D-08) trades round-trip for payload size — explicit decision; ChainOfTrust is the freight-counterparty graph for one load and is bounded by the 5-tier topology. |
| T-07-15 | Spoofing | Server fabricates a Load with verificationState manipulated | mitigate | Plan 01 fail-closed VerificationState decoder ensures unknown wire values → `.unverified`. Plan 01 fail-closed-to-suspicious ChainIntegrity.Verdict decoder ensures unknown verdicts → `.compromised`. Composes through Response.load → Load → TrustNode.verificationState. |
| T-07-16 | Denial of Service | Unbounded paginated envelope (`loads: [Load]` is unbounded array) | accept | Server side enforces page size; mock fixtures author at most ~10 loads per role list. A pathological server response would surface in the Phase 8 list as a performance issue, not a correctness failure. |
</threat_model>
