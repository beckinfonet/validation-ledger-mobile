## Test Infrastructure

| Property | Value |
|----------|-------|

| **Estimated runtime** | ~90 seconds per simulator lane (180s for the two-device R5/R10 phase gate) |

## Sampling Rate

- **After every task commit:** Run the new test suite for the touched component (e.g. after writing `RoleAvatarView.swift`, run `-only-testing:validationLedgerTests/RoleAvatarViewTests`). Latency ≈ 20-30s.
- **After every plan wave:** Run the full 9.1 test set on the scoped serial simulator lane.
- **Before `/gsd:verify-work`:** Full suite green on **iPhone 15 + iPad mini simulators** (two-device pass is the R5 + R10 contract — iPhone exercises new components; iPad exercises preserved TrustGraphView).
- **Max feedback latency:** 30 seconds (single suite); 180 seconds (full suite, two-device).

## R12 Grep Gates (TRUST-02 single-source-of-truth)

**Primary (call-site counting — least brittle):**

```bash
# R12 — exactly the two expected consumers may call DS.Colors.Verification.color(...).
expected_consumers=(
  "validationLedger/UI/Components/VerificationBadgeView.swift"
  "validationLedger/UI/Components/RoleAvatarView.swift"
)
actual=$(git grep -l 'DS\.Colors\.Verification\.color' -- 'validationLedger/**/*.swift' | sort)
expected=$(printf '%s\n' "${expected_consumers[@]}" | sort)
diff <(echo "$actual") <(echo "$expected") \
  && echo "R12 OK: exactly the expected consumers call the helper" \
  || { echo "R12 DRIFT: unexpected consumers or missing consumers"; exit 1; }
```

**Strict (no UIColor / `.systemX` literal / `.tertiarySystemFill` within 3 lines of a `VerificationState` case outside `Colors.swift`):**

> **W5 fix note (revision iteration 1):** the alternation now includes `\.tertiarySystemFill` in addition to `UIColor` and the `.systemX` family. Phase 9.1's RoleAvatarView pattern uses `.tertiarySystemFill` as the avatar fill for `.pending` states; this gate ensures no view file outside `Colors.swift` introduces a parallel switch over `VerificationState` mapping to that fill literal either.

```bash
for file in $(git grep -lE 'case \.(verified|pending|unverified|flagged):' \
              -- 'validationLedger/**/*.swift' \
              | grep -v 'Colors.swift'); do
    grep -A 3 -nE 'case \.(verified|pending|unverified|flagged):' "$file" \
      | grep -E '(UIColor|\.systemRed|\.systemBlue|\.systemYellow|\.systemGreen|\.systemOrange|\.systemPurple|\.systemTeal|\.tertiarySystemFill|DS\.Colors\.(primary|destructive|caution))' \
      && { echo "TRUST-02 VIOLATION in $file"; exit 1; }
done
echo "R12 strict gate OK"
```
